# SheetSet implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish an offline Android PDF score library with unlimited setlists, handwritten annotations, and annotated export.

**Architecture:** A single Compose app stores private PDF copies and an atomic JSON catalog. Android platform APIs render and export PDF pages. A custom page view owns zoom and drawing so annotation coordinates stay independent of screen size.

**Tech Stack:** Kotlin 2.3.21, Compose, Android API 26 to 36, `PdfRenderer`, `PdfDocument`, `AtomicFile`, JUnit 4, Compose UI tests, GitHub Actions, and static GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-08-20-sheetset-design.md`

## Global constraints

- Package ID: `cz.teply.sheetset`.
- No Internet permission and no runtime PDF dependency.
- Imported originals stay unchanged in app-private storage.
- UI strings live in resources for English, Czech, Slovak, German, and Polish.
- Every file operation runs off the main thread.
- Release starts at `0.1.0-alpha.1`.
